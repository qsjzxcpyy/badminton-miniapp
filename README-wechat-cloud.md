# 微信云开发部署说明

本仓库现在包含两部分：

- `frontend/`：原有 Vue/Vite 网页原型，继续使用浏览器本地数据。
- `miniprogram/` + `cloudfunctions/`：新增的原生微信小程序与云开发版本，比赛数据保存到云数据库。

## 开发者工具配置

1. 使用微信开发者工具导入仓库根目录 `badminton-miniapp`。
2. 在 `miniprogram/config.js` 把 `envId` 改为你的云开发环境 ID。
3. 在开发者工具开通云开发，并创建数据库集合 `matches`。
4. 将 `cloudfunctions/match` 上传并部署（云端安装依赖）。
5. 数据库集合 `matches` 可以先使用“所有用户可读、仅创建者可写”的宽松规则做体验；正式使用应改为仅允许云函数访问。
6. 点击编译，先创建比赛，再把体验版二维码发给已加入体验成员的朋友。

## 数据安全边界

普通球员通过 `getMatch` / `joinMatch` 只会收到球员姓名、状态、赛程、比分和排名，不会收到 `level`。创建者由微信 `OPENID` 识别，名单、等级和排赛操作只允许创建者执行。比分可以由普通球员提交，不记录操作者身份；云端使用 `revision` 防止两台手机同时写入时覆盖彼此的修改。

## 目前限制

本地环境不能模拟微信云数据库和多人微信身份。已验证的是纯排名、比分校验、排赛算法和构建；真实多人同步需要在开发者工具中配置你的云环境后，用两个微信体验账号实测。

## 后续发布

未发布时，体验版二维码通常只对开发者/体验成员开放。要让普通微信用户扫码访问，需要按微信公众平台规则完成审核发布。云开发免费额度和期限以官方计费页面为准，不应按永久免费设计。
