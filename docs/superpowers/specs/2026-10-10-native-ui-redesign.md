# 微信小程序界面优化：简洁布局

用户要求简洁、清晰、紧凑，保留按姓名筛选；删除候场球员，恢复创建者管理导航。其他页面可以增加少量颜色，管理员页面参考原体验版风格。

范围：原生微信小程序的布局、样式和已有交互。云函数及排赛算法保持现有实现。用户随后授权上传前端更新为新版体验版；用户已确认，2026-10-12 前端版本 `2026.10.10.1` 上传成功；公众平台当前体验版选中状态未通过工具确认。

视觉：浅灰背景 #f6f7f8，白色内容区域，正文 #28352f，次要文字 #78827c，分隔线 #e3e8e5。绿色 #238b68 用于主操作与当前状态；蓝色 #4d7db0 用于 B 队、已完成状态和加赛；橙色 #a46a28 用于连打提示和排名重点。配色集中在文字、圆点和小色签，无大面积装饰。

当前对局：姓名常规 16px、长姓名 15px，中等字重；比分提交按钮 13px。下一场姓名 14px。移除候场球员区域，保留下一场与简洁统计。姓名可点击打开个人赛程，比分加减只修改本地草稿。

赛程：白色列表、细线分隔，常规行高约 64–67px，姓名 13px。当前局使用淡绿背景与左侧细线；完成状态用蓝色。球员横向筛选与状态筛选组合使用。

排名：小型领先者摘要与紧凑列表，姓名 14px、净胜分 16px。头像用浅色区分，前三名序号以少量颜色强调。

管理：恢复创建者专属的底部“管理”入口，管理页也保留底部导航；参与者没有管理入口，页面切换函数阻止其进入管理。底部内容留出安全区。管理员名单恢复等级色签、浅色头像，绿色排赛、蓝色加赛与浅橙重开区域。参考来源为仓库改版前的已提交样式；尚未下载或确认云上体验版前端包，不能宣称逐项还原远端。

交互保留：姓名跳转个人赛程、组合筛选、比分草稿保护、提交去重、邀请码复制、历史比分编辑、下一场状态、未排赛与全部完成区分。

验证：本地回归、WXML/WXSS 编译、微信模拟器原生点击及截图。云请求在 API 层模拟，不写真实比赛。实际截图宽度 390px；320px 有适配规则，未做对应设备验证。刷新本地开发者工具。上传成功记录及体验版状态边界见 `docs/verification/ui-redesign/upload-2026.10.10.1.json`。
