# 管理员沿用邀请码重新开始比赛

用户场景：比赛中途希望重新开始，或下一次同一批球友继续活动，不用重新创建比赛和发邀请码。

- 在原生小程序管理员页面新增独立「重新开始并安排 15 局」按钮，执行前确认清空赛程、比分和排名；取消不写数据。
- 保留比赛 ID、名称、邀请码、创建者、名单和参赛状态，使用排赛 v3 对当前正常参赛球员生成全新 15 局。退出者继续不参与排赛。
- 不受旧比分、搭档及连打历史影响；默认第 1 局进行中，其余等待。现有赛程和比分被替换，排名依据新赛程归零，不提供历史归档或恢复。
- 既有重排待开始与追加操作保留原有语义。
- 云端 `restartMatch` 必须创建者身份和当前 revision，生成完整结果后才条件写入；失败不改旧比赛。
- 显示局号从 1 开始，内部 ID 从旧赛程最大 ID 后递增，避免旧比分误写；前端丢弃较旧 revision 快照。
- 确认及请求期间禁用赛程操作，等待已排队名单保存。普通球员通过已有轮询同步，并清空失效比分草稿及编辑窗口。
- 验证覆盖 6–9 人、中途/结束状态、复用邀请码、权限、取消、失败保留、条件更新冲突、多次重开、追加后编号、延迟比分及草稿清除。微信模拟器只使用临时数据，不重置真实比赛。
